# 吃大米饭 · v0.11.0

[在线游玩](https://cxcboss.github.io/chi-da-mi-fan/?v=0.11.0&build=74a92faa)

打开游戏即显示全部七个关卡，手机横竖屏与电脑均可直接选关。游戏底部常驻显示 v0.11.0。

白米饭锅、蛋炒饭锅、咖喱饭锅、海苔旋风饭、麻婆豆腐饭、黄金锅巴饭、暴走炒饭工厂。火候单独选择，“继续”恢复当前浏览器的锅入口检查点。

点击关卡，从对应锅开始向后闯关；完整七锅的纪录和火候解锁统计从第一锅开始的通关。开局空地可以先选年糕黏黏锤或火锅漏勺。

21 把厨房武器，包括回旋镖、芝士拉丝、冰冻碎击、锅贴地雷、远程吸饭勺和子弹时间，最终挑战暴走炒饭机。

手机左侧移动，右侧按住射击、拖动瞄准。电脑 WASD 移动、鼠标瞄准、左键/J 射击、空格跳、Shift 翻滚、Q 换武器、F 拾取/上勺、E 饱嗝、V 自动射击、B 自动瞄准、Esc 暂停。选关页按数字 1–7 直接进入对应关卡。

首次触摸请求全屏，自动射击、自动瞄准默认关闭。全屏取决于浏览器支持与系统限制；不支持的手机浏览器可以尝试添加到主屏幕。

进度和设置保存在当前浏览器本地，清理网站数据会清除存档。

此仓库保存可直接部署的静态发布文件。
