# 吃大米饭 · v0.10

[在线游玩](https://cxcboss.github.io/chi-da-mi-fan/?v=0.10.0)

手机横竖屏与电脑都可游玩。首次触摸请求全屏，自动射击、自动瞄准默认关闭。

七口锅、21 把厨房武器。开局空地可以先选年糕黏黏锤或火锅漏勺；新增回旋镖、芝士拉丝、冰冻碎击、锅贴地雷、远程吸饭勺和子弹时间，最终挑战暴走炒饭机。

手机左侧移动，右侧按住射击、拖动瞄准。电脑 WASD 移动、鼠标瞄准、左键/J 射击、空格跳、Shift 翻滚、Q 换武器、F 拾取/上勺、E 饱嗝、V 自动射击、B 自动瞄准、Esc 暂停。

进度和设置保存在当前浏览器本地；锅入口检查点可继续游玩。清理网站数据会清除存档。

全屏取决于浏览器支持与系统限制；不支持的手机浏览器可以尝试添加到主屏幕。

此仓库保存可直接部署的静态发布文件。
